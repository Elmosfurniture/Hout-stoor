Wood — Upload stock CSV

CSV columns: id, wood, supplier, grade, thick, L, W, qty, m3, dateIn
Afrikaans headers also work: NewNo, Hout, Verskaffer, HoutGraad, Thick, L, Width, Qty, m3, In — semicolon-separated files and comma-decimal numbers (e.g. 0,77) are handled automatically.
Extra columns if present — Bondel, Out, Week, R/m3, DNote — aren't used to build the stock row, but are saved for every row (even already-existing bundle IDs) and searchable on the Delivery records screen.
If a bundle ID already exists in stock it's skipped (won't overwrite live qty) — but its receiving data is still saved to Delivery records. New IDs are added as new bundles.
Receiving stock will automatically untick those items on the order checklist.

or drag and drop here

Steel — Upload stock CSV

CSV columns: code, description, type, supplier, qty, kgpm, price, cost, length
code is the unique ID (e.g. SQ25). If a code already exists it will be updated. New codes will be added.
type = category (e.g. Square Tube, Angle Iron). kgpm = kg per metre. price = sell price. cost = cost price. length = stock length in metres.
